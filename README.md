# GoBanana — CD Preview (Landing Page)

نسخة السي دي من صفحة الهبوط. الهيرو فيه علبة سي دي يطلع منها السي دي ويلف، وتحت مشغل بشكل Discman، والـ Tracklist مصمم كظهر علبة السي دي. وبعدها المودلز (علب سي دي)، المساحة، الباقات، والفوتر. وتدعم عربي/إنجليزي.

---

## التشغيل على جهازك

### ١. المتطلبات
- **Node.js** الإصدار 18 أو أحدث، من https://nodejs.org
- **VS Code**

### ٢. أول مرة
افتح المجلد في VS Code، ثم افتح الـ Terminal (من القائمة: Terminal ← New Terminal) واكتب:
```bash
npm install
```

### ٣. التشغيل
```bash
npm run dev
```
تنفتح الصفحة على `http://localhost:5174`، وأي تعديل تحفظه يظهر مباشرة.

### ٤. نسخة النشر
```bash
npm run build
```
يطلع مجلد `dist` جاهز ترفعه على أي استضافة.

> بديل بدون Node: افتح المجلد في VS Code وشغّل `index.html` بإضافة **Live Server**.

## بدائل مؤقتة لازم تتبدل قبل الإطلاق
1. **الشعار:** مكتوب بخط قريب منه. استبدله بملف SVG الأصلي (`.logo` و `.print`).
2. **خط Satoshi:** مستبدل بـ Plus Jakarta Sans. نزّله مجانًا من https://www.fontshare.com/fonts/satoshi، وحطه في `public/fonts`، وأضف `@font-face`.
3. **الخط العربي:** IBM Plex Sans Arabic مؤقت.
4. **صور المودلز:** رسومات بنمط الفوتوكوبي (الدالة `sil` في `main.js`). استبدلها بالصور الحقيقية.
5. **الباقات والأسعار والنصوص:** عينات.

> الموقع يحتاج إنترنت وقت التشغيل عشان الخطوط (Google Fonts).
